# Harigovind P — Developer Portfolio

Personal developer portfolio built to showcase projects, skills, and background.

🔗 **Live site:** [harigovindp.me](https://harigovindp.me)

## Tech Stack

- **React + TypeScript** — component-based UI
- **Vite** — build tooling and dev server
- **shadcn/ui** — accessible, composable UI components
- **Vercel** — hosting and deployment

## Getting Started

```bash
# Clone the repo
git clone https://github.com/harigovindmelath/Portfolio_harigovind.git
cd Portfolio_harigovind

# Install dependencies
pnpm install

# Run locally
pnpm dev
```

The site will be available at `http://localhost:5173` (Vite's default port).

## Deployment

Deployed on [Vercel](https://vercel.com) — auto-deploys on push to `main`.
